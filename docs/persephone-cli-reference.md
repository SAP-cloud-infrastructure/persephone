`scikube` is the CLI tool for interacting with Persephone. It generates kubeconfig files and provides a kubectl authentication plugin.

## Installation

Download the binary from the [releases page](https://github.com/sap-cloud-infrastructure/persephone/releases).

## Commands

### kubeconfig-for-garden

Create a kubeconfig file for a Persephone garden cluster (management plane).

```bash
scikube kubeconfig-for-garden [flags]
```

**Flags:**

| Flag | Description | Default |
|------|-------------|---------|
| `--landscape` | Persephone landscape (`prod`, `canary`, or `qa`) | `canary` |
| `--os-auth-url` | OpenStack Keystone API URL | `$OS_AUTH_URL` |
| `--os-username` | OpenStack username | `$OS_USERNAME` |
| `--os-password` | OpenStack password | `$OS_PASSWORD` |
| `--os-domain-name` | OpenStack domain name | `$OS_DOMAIN_NAME` |
| `--os-project-name` | OpenStack project name | `$OS_PROJECT_NAME` |
| `--os-project-domain-name` | OpenStack project domain name | `$OS_PROJECT_DOMAIN_NAME` |
| `--os-user-domain-name` | OpenStack user domain name | `$OS_USER_DOMAIN_NAME` |
| `--os-region-name` | OpenStack region name | `$OS_REGION_NAME` |
| `--os-application-credential-id` | Application credential ID | `$OS_APPLICATION_CREDENTIAL_ID` |
| `--os-application-credential-name` | Application credential name | `$OS_APPLICATION_CREDENTIAL_NAME` |
| `--os-application-credential-secret` | Application credential secret | `$OS_APPLICATION_CREDENTIAL_SECRET` |
| `--project-id` | Manually set project ID (skips Keystone lookup) | `$SCIKUBE_PROJECT_ID` |
| `--url` | Manually set Persephone URL (skips catalog lookup) | `$SCIKUBE_URL` |
| `--debug` | Enable debug output | `$SCIKUBE_DEBUG` |

### kubeconfig-for-shoot

Create a kubeconfig file for a shoot cluster.

```bash
scikube kubeconfig-for-shoot [flags]
```

**Flags:**

| Flag | Description | Default |
|------|-------------|---------|
| `--name` | The shoot cluster name | `$SCIKUBE_SHOOT_NAME` |
| `--kubeconfig` | Path to the garden cluster kubeconfig | `$KUBECONFIG` |
| `--expiration` | Kubeconfig expiration duration | `8h` |

**Requires:** A valid garden kubeconfig set via `--kubeconfig` flag or `KUBECONFIG` environment variable.

### auth

kubectl authentication plugin. This command is used internally by kubeconfig files generated by `scikube` and is typically not invoked directly.

```bash
scikube auth [flags]
```

### completion

Generate shell autocompletion scripts.

```bash
scikube completion [bash|zsh|fish|powershell]
```

## Environment Variables

| Variable | Description |
|----------|-------------|
| `SCIKUBE_LANDSCAPE` | Default landscape for `kubeconfig-for-garden` |
| `SCIKUBE_SHOOT_NAME` | Default shoot name for `kubeconfig-for-shoot` |
| `SCIKUBE_SHOOT_KUBECONFIG_EXPIRATION` | Default kubeconfig expiration |
| `SCIKUBE_PROJECT_ID` | Override project ID |
| `SCIKUBE_URL` | Override Persephone URL |
| `SCIKUBE_DEBUG` | Enable debug output |

All standard `OS_*` OpenStack environment variables are supported.

## Typical Workflow

```bash
# Source your OpenStack credentials
source my-project-openrc.sh

# Generate garden kubeconfig
scikube kubeconfig-for-garden --landscape prod > garden-kubeconfig.yaml

# Export password if using password authentication
export OS_PASSWORD='...'

# Generate shoot kubeconfig
export KUBECONFIG=garden-kubeconfig.yaml
scikube kubeconfig-for-shoot --name my-cluster --expiration 1h > shoot-kubeconfig.yaml

# Use the cluster
export KUBECONFIG=shoot-kubeconfig.yaml
kubectl get nodes
```
